# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

People practicing AI development concepts through short quizzes (inferred from the project brief).

## Product Purpose

Help users test and build knowledge with five-question quizzes, explanations, repeat attempts, and visible progress.

## Operating Context

A browser-based simulated backend with explicitly controllable failures. Users can resume a quiz after a refresh while server session state is available.

## Capabilities and Constraints

Three AI development categories; optional Learn Mode; server-validated answers; cumulative leaderboard; local progress history. The in-memory backend is a demo and loses state on restart. See SPEC.md.

## Brand Commitments

The product is called QuizApp. No existing visual identity was provided.

## Product Principles

- Make the next action and current quiz state clear.
- Keep learning feedback useful and easy to revisit.
- Handle uncertain responses without changing or duplicating an answer.
- Make progress and simulated failures understandable.
